# 教学界面优化

沿用用户已批准的电脑左参数、右波形及手机底部可展开面板，执行本轮ui-ux-pro-max优化授权。技术栈保持React/TypeScript。

比较：纯换色改善有限；整体导航重构改变已确认流程。选择在现有教学布局内优化信息层级、对比度、参数分组及触控。

采用检索中Accessible & Ethical的可读性、焦点和触控建议，以及real-time-monitoring样式的实时状态与波形优先原则。营销落地页、轮播、声音、闪烁等建议不适用于本项目，舍弃。React检索未发现需要凭空增加memo化的理由，保留现有引擎。

具体执行：统一青绿色语义色与深色波形；提高中文字号；参数分为主要设置、送气与切换、组合、后备；锁定项目保持原生禁用并折叠为可展开说明；数字框编辑后回车或离开时提交，滑块仍直接生效；提供逐字段错误关联、模式选中状态、键盘跳转、SVG图标、安全区及减少动效支持。三波形持续运行、固定坐标、医学算法与模式参数权限不变。

检查：既有68项测试、构建，桌面及手机浏览器操作、无横向溢出、锁定状态及可访问性审计。桌面与手机截图人工查看。
