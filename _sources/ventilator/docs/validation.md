## 已知边界与后续工作

1. 参数范围、控制器常数、C/R映射及气体交换响应为明示的教学模型配置，不能解释为厂商精确仿真或临床处方。参见evidence.md。
2. 未实现肺复张、过度扩张、循环及代谢性酸碱变化，符合批准的首版模型边界。容量为相对初始基线而非绝对肺容量。
3. 反馈算法依公开原理构建，VG/PRVC/VSV按各自配置测量量调节；不声称复刻专有算法。特别是新生儿VG资料只支持反馈概念，不证明15kg参数的临床适用性。
4. 页面、参数及解释需要用户或指定专业人员完成医学审阅；目前未做真人学习成效评估及完整真实设备交叉验证。
5. 还未在物理手机Safari/Android上做实机验证；当前手机验证是桌面浏览器的移动视口。
6. 当前仅本机预览。源码和静态构建已备齐；托管账户、域名及正式发布尚未执行。
