# 教材对照复核与修正

## 阅读范围
重新定位用户原PDF《儿童机械通气2023版》，以已有逐页OCR为检索入口，重新查看相关章节条目和原图。书页与PDF页序相差18。重点：第7章137页传感器位置；第8章153—155页VC/PC、164页PSV、178页PRVC、182—183页VAPS/VSV；第9章224—225页时序与RC、227—229页Vti/Vte及流量；第10章250页动态充气及PEEPi。原图核对154、182、224、228、250页。不声称完成958页全书逐页精读。原文及原图仅保存在本地，不随网页发布。

## 教授所举关系的复现
被动、无漏气、未限压的VC，送气时间0.6秒、暂停0.1秒：Vt60/120/180mL分别对应方波6/12/18L/min。原引擎已有Vt/Tflow公式，不能把曲线观察问题笼统认定为公式缺失。旧测试没有断言波形幅度、送气时间变化和显示流量积分，验收覆盖不足。数值输入需回车或失焦提交，呼吸设置于下一次吸气生效；固定±60L/min坐标使小流量变化不醒目，这些是实际观察时需分辨的因素。

## 已确认的错误与修正
1. 旧曲线吸气使用设备送气流量，容量却使用肺内气量；漏气时面积不对应。现统一显示肺端流量Qlung=dVlung/dt，设备端Vti/Vte仍单独监测并标示。
2. 旧代码先切换phase，再按新phase选择显示流量，抹掉最终吸气积分步；在暂停漏气时还将非零肺端流量显示成零。现按本步实际积分流量绘制，不以末态阶段覆写。
3. VAPS旧实现按PSV峰流量百分比ETS转入补充，和教材182页的预设VA-CV流量阈值不符。现按流量下降至预设补充流量且容量不足转换，锁定不适用ETS。maxTi保持可调教学保护值，不照搬某设备3秒硬限。
4. VC递减流量用区间中点计算归一化轮廓，减少左端采样偏差；保持目标Vt和送气时间相同。
5. VC/SIMV-VC波形上方新增Vt/Tflow的设定平均流量、总Ti与下一指令吸气生效说明；曲线注明肺端测量位置，并显示实时数值。平均流量是设定计算结果，限压/漏气时不冒充实际肺端结果。

## 继续存在的模型边界
单室线性C/R、简化容量反馈、未充分补偿的近端漏气。第10章涉及肺复张、过度扩张和循环效应，当前没有相应模型，不添加伪造的PEEP氧合收益。血气为简化教学估计，不能用于评价临床处方。PRVC/VG/VSV具体厂商的试探呼吸、漏气补偿、压力安全边界不同，目前不宣称复刻某设备。VAPS为历史模式原理演示。

## 复核方法
新增tests/textbook-relations.test.ts：VC容量与流量比例、送气时间反比、暂停独立性、波形面积、C/R作用、全积分步流量与肺容量守恒（含漏气与切换）、VAPS阈值及RC相关气体陷闭。既有测试继续运行。测试通过不代表已经完成独立医学审阅。
