# 儿童呼吸机原理实验室

固定15 kg儿童的通用教学模拟器。电脑、平板、手机均可调节全部适用参数并观察动态三波形。当前为开发预览，临床数值与模型解释仍需专业审阅；不用于患者治疗决策。

## 运行和验证

Node.js 24，安装锁定依赖后运行：

```powershell
npm ci
npm run dev -- --port 5178
npm test
npm run build
```

打开终端显示的本地URL。生产产物位于dist，可部署到支持HTTPS的静态托管；当前尚未发布到公网。

## 内容和参数维护

- `src/config.ts`：参数定义、教学范围、初始值、模式说明及参数适用性。
- `src/engine.ts`：连续力学、呼吸序列、容量反馈、触发、后备、统计与简化气体交换。
- `src/main.tsx`：页面布局、短说明、模式切换和动态Canvas；`src/style.css`控制响应式布局。
- `docs/evidence.md`：来源、算法取舍与教学假设。更改数值或公式时同步修改依据并运行相关测试。
- `tests/engine.test.ts`：确定性的控制器及模型核验；`tests/browser-audit.js`可通过agent-browser eval --stdin在已打开页面执行UI检查。

## 使用提示

模式直接切换；患儿状态保留。手机点底部“展开参数与患儿设置”后自动定位三条波形。PSV窒息后进入后备PC-A/C，需点击“手动返回PSV”。VTV对照页复用VGV、PRVC、VSV、VAPS控制器。

设置变更通常在下一口相关呼吸生效。启动时分钟统计等待完整60秒窗口。页面处于后台时冻结模拟时钟，回前台不补算休眠时间。参数恢复初始会清空当前轨迹。

第一版不模拟PEEP复张、过度扩张、循环效应和代谢性酸碱改变；漏气和容量反馈是明示的教学近似。波形容量为相对初始基线变化，不能解读为绝对肺容量。源资料与实际模型不完全等价，详见依据文件和页面模型说明。

参数开放仅针对当前模式可直接设置的项目；自动调节、计算结果及不适用项目灰显锁定并说明原因。SIMV的PSV/VG开关联动权限，计算层同时拒绝锁定字段修改。

界面已按ui-ux-pro-max优化：参数按用途分组、锁定原因折叠、中文字号与触控放大。数字框按回车或移开焦点后提交；滑块仍实时生效。设计取舍见docs/ux-refinement.md。
